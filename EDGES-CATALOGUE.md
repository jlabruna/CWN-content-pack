# CWN Operator Edges

This pack contains the 14 standard Operator Edges as native SWNR `feature` Items with `system.type: edge`, plus a non-selectable Underdog Rule reference Item.

Rules text is an original, concise paraphrase. Declarative metadata under `flags.cwn-content-pack` identifies each Edge, its bonus-skill award, configuration requirements, and safe automation hooks for CWN Combat Enhancements. The Content Pack itself does not alter actors or rolls.

The Underdog reference is not a fifteenth selectable Edge. It records the character-creation eligibility and advancement restrictions for manual adjudication.
